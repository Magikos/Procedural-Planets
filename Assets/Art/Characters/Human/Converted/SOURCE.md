# Cached outfit conversions

These outputs derive from the existing Townsfolk character model, Townsfolk material, human reference prefabs, and reviewed fitting code. No vendor files were added.

Use **Tools > Actors > Human > Outfit Converter**. Each revision folder contains a source comparison prefab, a fitted prefab, a cached mesh, and a conversion receipt. Keep the receipt with the output. Use a new revision after source or authored-output changes.

The initial Rider and Priest v1 meshes match their accepted wardrobe conversions exactly. Priest requires further cloth review. The converter does not extract integrated hoods or add cloth simulation.

Workflow and validation: `docs/design/2026-09-11-sidekick-outfit-converter.md`.
