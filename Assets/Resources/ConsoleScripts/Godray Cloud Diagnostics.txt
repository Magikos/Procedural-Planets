# Diagnostic sweep for the god-ray / cloud-consistency feedback round (2026-07-11).
# Every screenshot's .txt sidecar records the exact knob values active for that shot
# (via @sidecar above) - no need to cross-reference this script to know what was tested.
#
# History (2026-07-11):
# - Run 1 (natural weather): scenario A and C landed on whatever cloud coverage happened
#   to exist at run time - inconclusive when re-run later, since weather kept evolving.
# - Run 2: added weather.force for scenario A/C so coverage is guaranteed and repeatable
#   regardless of when the script runs. Also revealed forcing UNIFORM coverage removes the
#   PATCHINESS that likely caused the original altitude complaint - a real, useful finding,
#   but it means scenario A tests "does feather matter at uniform density" (subtle effect),
#   not the original patchy-coverage symptom. To reproduce THAT, catch it live and use
#   weather.freeze true (no force) to lock the actual natural pattern before it drifts.
# - Run 2/3: scenario B's off-center shots used a hardcoded camera Forward vector computed
#   from an old reference screenshot, assuming the sun would still be roughly where it was
#   in that reference. It wasn't - sun position drifts with real elapsed session time even
#   with time.freeze (freeze holds wherever the sun CURRENTLY is, not a specific historical
#   position), so the hardcoded aim silently went stale and pointed at empty sky.
# - Run 4 (current): replaced all hardcoded "aim at the sun" vectors with
#   camera.look-at (position only) -> time.set-local (sun placed deterministically RELATIVE
#   TO that camera position, immune to real-time drift) -> camera.face-sun (exact aim at
#   wherever the sun actually ends up). This is fully deterministic regardless of when the
#   script runs. Scenario B's off-center shot now works by changing time.set-local a second
#   time WITHOUT re-calling face-sun - the sun moves in the sky, the camera doesn't follow,
#   so it lands off-center by a known, controlled amount instead of a hand-computed guess.
#
# IMPORTANT: weather.force is PLANET-WIDE (all 6 cube faces, uniformly) - not scoped to the
# camera. Each scenario sets the weather state IT needs at the start of its own block;
# nothing resets automatically between scenarios.

time.freeze true

# --- Scenario B: god-ray reach, sun dead-center vs shifted off-center in the same frame.
# --- Tests whether "reach" fixes the glow shrinking away from the sun complaint.
# --- Forced fully clear so the sun-glow geometry test is isolated from cloud interaction
# --- entirely (a forced uniform value has no noise-based shape/gaps of its own).
# --- Center: face-sun at local noon (0.5) - guaranteed correct regardless of real time.
